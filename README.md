## 캠페이너스에 붙이는 구조 — 제일 중요

**각 페이지는 개별 코드 위젯 하나, 상단과 하단은 각각 반복 섹션 한 곳.**

- `index.html` · `activity-*.html` · `issue.html` · `dok-history.html` · `library.html` 은
  각각 **코드 위젯 하나에 파일 전체**를 붙입니다. 범위는 파일 안의
  `CAMPAIGNERS:PAGE-CODE START/END`.
- 페이지 파일에는 공통 상단·하단이 **일부러 없습니다.** `#ah-nav` 나 `#ah-foot` 를
  페이지 코드에 넣으면 반복 섹션과 겹쳐 두 번 나옵니다.
- **공통 상단 원본 = `tools/parts/header.html` 한 곳.** 파일 전체를 **페이지 맨 아래**
  코드 위젯에 붙이고 그 섹션을 `섹션 반복` 으로 설정합니다(반복은 맨 아래에서만 켜집니다).
  위젯은 아래 있어도 헤더는 화면 위에 고정됩니다.
- **공통 하단 원본 = `tools/parts/footer.html` 한 곳.** 기본 푸터 바로 위 코드 위젯에
  붙이고 역시 `섹션 반복`.
- 캠페이너스 기본 상단·푸터는 우리 코드가 숨깁니다. 하단 디자인을 또 만들지 않습니다.

⚠️ **하단(`footer.html`)은 상담소와 밑빠진 독상이 읽어 갑니다**(베끼지 않습니다).
하단을 고쳤으면 두 저장소에서 한 번씩 다시 구우세요.

    participatory-budget:  python build.py
    dokseong:              python tools/port-footer.py

**활동 셋은 게시판을 사이에 두고 나눠 붙입니다** — `/49` 지자체 감시 · `/27` 예산감시 ·
`/51` 시민참여. 순서는 `activity-<이름>-before-board.html` → 그 페이지 기본 게시판 위젯 →
`activity-<이름>-after-board.html` → 공통 하단. 미리보기용 전체 파일
(`activity-local.html` 등)을 붙이지 않습니다. `/76` 은 이 구조에서 제외.

자세한 배치 순서와 원본·생성물 구분은 **`CAMPAIGNERS_CODE_SPLIT.md`** 가 기준입니다.

⚠️ **붙인 뒤에는 고치기가 비쌉니다.** 화면 하나를 고치면 그 화면을 손으로 다시 붙여야
합니다. 큰 수정은 붙이기 전에 몰아서 끝내세요. 공통 상단·하단만 예외입니다(한 곳).

## 알려진 함정

- ⚠️ **캠페이너스는 코드 위젯들의 스크립트를 `<script>` 하나로 이어 붙입니다.**
  그래서 **한 화면의 문법 오류 하나가 그 페이지의 공통 상단까지 같이 죽입니다.**
  2026-09-14 에 `/74` 가 그랬습니다 — 숫자가 `0년`·`0회` 에서 멈추고, 떠 있는 후원
  버튼이 안 뜨고, 고정 헤더 자리잡기도 안 돌았습니다. 원인은 한 곳이었습니다.
  화면을 붙이기 전에 **인라인 스크립트가 파싱되는지** 한 번 보세요.
- ⚠️ **`.num` · `.label` 같은 범용 클래스 이름을 쓰지 마세요.** 캠페이너스(imweb)
  전역 CSS 에 같은 이름이 있습니다 — `function.css` 의 `.num` 은 22×22 알림 배지,
  `vendor_blue_10.css` 의 `.label` 은 부트스트랩 라벨입니다. 우리 규칙이 더 세도
  **우리가 안 적은 속성(display·width·white-space)은 그쪽 값이 그대로 먹습니다.**
  화면 전용 이름을 쓰고, display 는 직접 적으세요.
  ⚠️ **덩이에 붙은 이름이 더 위험합니다.** 홈 큰 칸의 `.lead` 가 부트스트랩
  `.lead{font-size:21px;font-weight:300}` 를 맞아 **안쪽 글자가 전부 가는 글씨로
  물려받고** 있었습니다(2026-09-14 에 막았습니다). 지금 걸려 있는 이름은
  `.num` · `.label` · `.lead` · `.mark` · `.badge` 다섯입니다 — 새 이름을 지을 때
  **한 낱말짜리 흔한 이름을 피하세요.** 의심되면 그 `.css` 를 `curl` 로 받아
  같은 이름이 있는지 보고, 브라우저에서 **잰 값**으로 확인하세요.
- **RSS 주소의 `&amp;`** — `...&amp;bmode=view` 로 옵니다. 그대로 넘기면 한 번 더 감싸져
  `&amp;amp;` 가 되어 링크가 깨집니다. 엔티티를 풀어서 넘기세요.
- **RSS 날짜** — `Tue, 25 Aug 2026 …` 입니다. `2026.08.25` 로 바꿔서 넘기세요.
- **알약 목차는 `.is-hover`(스크립트)로 엽니다.** CSS `:hover` 로 되돌리지 마세요 —
  알약에서 판으로 커서를 내리는 사이에 닫혀 버립니다.
- **회원가입을 `/join` 으로 걸지 마세요.** 거기는 후원 화면입니다.
- **`tools/build-activity.py` 의 `AH_SCRIPT`** 가 만드는 조각은 `build_nums` ·
  `build_now` · `build_result` · `build_posts` · `build_photos` 가 만드는 것과 모양이
  같아야 합니다. 한쪽만 고치면 게시판을 물리는 순간 화면이 달라집니다.
  (스크립트를 `TEMPLATE` 안에 넣지 마세요 — `.format()` 문자열이라 중괄호를 두 번 써야 합니다.)
- **큰 칸 카드는 통째로 `<a>` 가 아닙니다.** 제목 링크(`.slide-go`)가 `::after` 로 카드를
  덮습니다. 그래야 카드 안에 다른 링크를 둘 수 있습니다.
- **`tools/check.py --net` 은 인증서 문제를 못 잡습니다**(`ssl.CERT_NONE`).
  HTTPS 는 `openssl s_client -connect <주소>:443 -servername <주소>` 로 직접 보세요.
- **좌우 여백은 48 / 36(820px) / 28(430px)**, 바깥 폭은 **1120px 가운데 정렬**.
  새 화면도 이 값을 씁니다. 음수 여백을 쓰지 않습니다.
- **하늘색(`--brand` #00afec) 위 흰 글씨는 대비 2.5:1** 로 기준 미달입니다. 단체 색이라
  사람이 정할 일이라 두었습니다. 고치려면 흰 글씨가 얹히는 곳만 `--brand-deep`(4.1:1).

```

# dist/ 를 action-home-preview 저장소에 밀어 넣는다 (.git · README.md 는 남긴다)
```
