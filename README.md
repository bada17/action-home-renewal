# 함께하는 시민행동 홈페이지 개편

`action.or.kr` 홈페이지 개편 시안을 안전하게 협업하기 위한 비공개 저장소입니다.

## 전체 구조 (2026-08-25 확정)

홈페이지에 들어온 사람이 랜딩페이지를 먼저 보고, 더 들어가면 개편안 홈으로 가는 구조입니다.

```
action.or.kr           →  donate.action.or.kr 로 보냄   ← redirect-snippet.html
donate.action.or.kr    =  랜딩 = 현관                    ← 별도 저장소 action-landing
   └ [홈페이지] 링크
action.or.kr/69        =  개편안 홈 = 안쪽               ← 이 저장소의 index.html
```

- 랜딩을 이 저장소로 복사하지 않습니다. 랜딩은 `img/` 사진 16장과 매일 자동
  갱신되는 `data/news.json` 을 자기 서버에서 끌어다 쓰기 때문에, 옮기면 사진이
  깨지고 소식 카드가 멈춥니다. 원본 한 벌만 두고 그대로 씁니다.
- 대신 주소창에는 `donate.action.or.kr` 이 뜹니다. 이 점은 확인받았습니다.
- 홈에서 현관으로 돌아가는 길은 상단 '후원하기'(donate.action.or.kr)입니다.

### 홈 주소를 확정하면 같이 고칠 곳

지금 개편안 홈 주소는 캠페이너스 숨김 페이지 `/69` 입니다. 확정되면 두 군데를 함께 바꿔야 합니다.

1. 이 저장소 `redirect-snippet.html` 의 주석과 안내 문구
2. `action-landing` 저장소 `index.html` 에서 `to-home` 으로 검색되는 링크 **네 곳**
   (상단바 로고, 상단바 '홈페이지', 맨 아래 띠, 푸터)

`/69` 는 숨김 페이지이므로, 주소를 확정하기 전에 리다이렉트를 켜면 시안이 공개됩니다.

## 파일

| 파일 | 무엇 | 캠페이너스 주소 |
|---|---|---|
| `index.html` | 홈 | `/69` (숨김) |
| `activity-local.html` | 활동 &gt; 지자체 감시 | `/49` |
| `activity-power.html` | 활동 &gt; 권력감시 | 아직 없음 |
| `activity-budget.html` | 활동 &gt; 예산감시 | 아직 없음 |
| `activity-*.html` 셋 | ← `tools/build-activity.py` 가 만듭니다. **직접 고치지 마세요** | |
| `dok-history.html` | 활동 &gt; 밑빠진 독상 (역대 기록) | 아직 없음 |
| `issue.html` | 이슈 목록 | 아직 없음 |
| `redirect-snippet.html` | 대표 홈 → 랜딩. **아직 적용 안 함** | |
| `DESIGN.md` | 다섯 화면이 공유하는 색·글꼴·모양 한 벌 | |
| `tools/build-activity.py` | 활동 페이지 세 장을 한 틀에서 찍어냄 | |
| `tools/preview.py` | 미리보기 서버 | |
| `tools/sync-dok.py` | 밑빠진 독상 원본 디자인이 바뀌었는지 점검 | |

활동 = **끝나는 날짜가 없는 일** 다섯입니다.
지자체 감시 · 권력감시 · 예산감시 · 시민참여 · 밑빠진 독상.
(기업 감시는 사용자 확정으로 **내년** 일입니다.)

## 미리보기

```
python tools/preview.py          →  http://127.0.0.1:8777/
python tools/preview.py 8899     →  포트를 바꿔서
```

이 저장소의 `.html` 은 통째로 된 문서가 아니라 **캠페이너스 코드 위젯에 붙일 조각**입니다.
`<head>` 가 없어서 파일을 그냥 열면 한글이 깨집니다. 이 서버가 charset 을 씌워 줍니다.
활동/이슈 페이지가 서로를 `/49`, `/act-power` 로 가리키므로 링크도 여기서만 이어집니다.

`/pb/` 와 `/dok/` 는 **복사하지 않고** 옆 저장소(참여예산 상담소 · 밑빠진 독상)를
그 자리에서 읽습니다. 거기서 고치면 여기서도 바로 보입니다.

## 현재 단계

- `index.html`은 캠페이너스 숨김 페이지 `/69`에 적용한 HTML/CSS 코드 위젯 시안입니다.
- 현재 공개 홈페이지와 캠페이너스의 기존 페이지·게시물·메뉴 데이터는 이 저장소와 분리되어 있습니다.
- 디자인 확정 후 캠페이너스 기본 위젯과 게시판 연결 방식으로 재구성할 예정입니다.

## 작업 원칙

- 2026년 9월 10일 전에는 기존 공개 홈페이지를 수정하거나 교체하지 않습니다.
- 승인 없이 캠페이너스에서 게시, 대표 홈 전환, 공통 헤더·메뉴 변경을 하지 않습니다.
- 기존 페이지·게시물·자료·URL은 삭제하지 않습니다.
- 회원·후원자 개인정보, 로그인 정보, 인증 토큰, 관리자 데이터 백업은 저장소에 올리지 않습니다.
- 시안 변경은 우선 `index.html`에서 진행하고, 승인된 버전만 숨김 페이지 `/69`에서 검수합니다.

## 확정된 기본 방향

- 상단 메뉴: 소개 · 활동 · 이슈 · 소식 · 후원하기 (자료실은 없애고 발행물·뉴스룸을 소식 밑으로)
- 진행 중인 캠페인을 홈 전면에 배치
- 완료된 캠페인은 결과와 후속 활동 중심으로 정리
- 후원하기: <https://donate.action.or.kr/>
- 새 메뉴에서 제외하더라도 원본 데이터는 보존

## 캠페이너스에서의 최종 검수

캠페이너스의 실제 글꼴·공통 스타일·`<script>` 실행 여부는 숨김 페이지 `/69` 에서
따로 확인해야 합니다. 미리보기와 다를 수 있습니다.
