## 2026-09-01 — 첫 화면에 캠페인만 오르지 않습니다

### 첫 화면 (`index.html` 의 `.lead`)

- **중요한 글도 함께 오릅니다.** 고르는 규칙은 **게시판 글 제목 맨 앞에 `[주요]`**.
  최신순 두 건까지. 알약에 무엇이라고 적힐지는 `[주요:논평]` → 제목 머리말(`[논평]`
  `활동가 수첩_`) → 게시판 이름 순으로 정합니다. **자세한 것은 `CONTENT.md`.**
- 알약을 다시 짰습니다 — **종류(캠페인·논평…) + 갈래(예산감시…)** 둘을 나란히,
  채우지 않고 **테두리형**으로(사용자가 준 이미지 방식). '진행 중' 알약은 삭제했습니다.

  멈춥니다.' 를 뺐습니다.

홈에만 있던 자리를 **캠페인 목록과 활동 네 장**에도 냈습니다.

   ⚠️ 제목 · 한 줄 · 결과 · 사진은 데모에 **일부러 안 넣었습니다.** 채우려면 지어내야 하는데,

5. **조사 19곳** — '이슈'→'캠페인' 일괄 치환 때 어긋난 것을 고쳤습니다

### 스크립트를 고칠 때 주의

활동 페이지의 갈아 끼우는 스크립트는 `tools/build-activity.py` 의 **`AH_SCRIPT`** 에
있습니다. TEMPLATE 안이 아닙니다 — TEMPLATE 은 `.format()` 문자열이라 중괄호를 전부
두 번 써야 하고, 자바스크립트를 거기 넣으면 하나만 빠뜨려도 조용히 깨집니다.

⚠️ **`AH_SCRIPT` 가 만드는 조각은 `build_nums` · `build_now` · `build_result` ·
`build_posts` · `build_photos` 가 만드는 것과 모양이 같아야 합니다.** 한쪽만 고치면
게시판을 물리는 순간 화면이 달라집니다.

  화면에 그대로 찍힙니다.

## 전체 구조 (2026-08-25 확정)

홈페이지에 들어온 사람이 랜딩페이지를 먼저 보고, 더 들어가면 개편안 홈으로 가는 구조입니다.

```
action.or.kr           →  donate.action.or.kr 로 보냄   ← redirect-snippet.html
donate.action.or.kr    =  랜딩 = 현관                    ← 별도 저장소 action-landing
   └ [홈페이지] 링크
action.or.kr/69        =  개편안 홈 = 안쪽               ← 이 저장소의 index.html
```

- 랜딩을 이 저장소로 복사하지 않습니다. 랜딩은 `img/` 사진 16장과 매일 자동
  갱신되는 `data/news.json` 을 자기 서버에서 끌어다 쓰기 때문에, 옮기면 사진이
  깨지고 소식 카드가 멈춥니다. 원본 한 벌만 두고 그대로 씁니다.
- 대신 주소창에는 `donate.action.or.kr` 이 뜹니다. 이 점은 확인받았습니다.
- 홈에서 현관으로 돌아가는 길은 상단 '후원하기'(donate.action.or.kr)입니다.

### 홈 주소를 확정하면 같이 고칠 곳

지금 개편안 홈 주소는 캠페이너스 숨김 페이지 `/69` 입니다. 확정되면 두 군데를 함께 바꿔야 합니다.

2. `action-landing` 저장소 `index.html` 에서 `to-home` 으로 검색되는 링크 **네 곳**

`/69` 는 숨김 페이지이므로, 주소를 확정하기 전에 리다이렉트를 켜면 시안이 공개됩니다.
